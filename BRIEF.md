## 一、背景

### Pi 是什么

- Pi 是一个开源（MIT）终端 AI 编程 Agent，由 Mario Zechner（libGDX 作者）创建
- 在 Terminal-Bench 2.0 基准测试中排名第 2，超过 Claude Code 和 Cursor
- 核心优势：极简（4 个工具 / 200 行 system prompt）、Token 成本为 Claude Code 的 30-35%、支持 20+ 模型提供商

### pi-web 是什么

- pi-web (`@agegr/pi-web`) 是 Pi 的本地 Web 界面（Next.js + React）
- 通过浏览器访问 `localhost:30141`，提供会话管理、实时对话、文件浏览等功能

### 中文化方案（推荐 preload 注入）

不 fork pi-web 源码，用 Electron preload 注入翻译脚本：

```js
// preload.js 示意
const ZH_MAP = {
  "New Session": "新建会话",
  "Send Message": "发送消息",
  Settings: "设置",
  // ... 完整字典
};

// MutationObserver 监听 DOM，自动替换英文→中文
const observer = new MutationObserver(() => {
  document.querySelectorAll("*").forEach((el) => {
    if (el.childNodes.length === 1 && el.childNodes[0].nodeType === 3) {
      const text = el.textContent.trim();
      if (ZH_MAP[text]) el.textContent = ZH_MAP[text];
    }
  });
});
observer.observe(document.body, { childNodes: true, subtree: true });
```

**优点**：pi-web 升级不受影响，翻译失败只显示英文原文，不破坏功能。
