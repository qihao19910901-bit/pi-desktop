> 日期：2026-08-10

## 1. 调研结论

### 1.1 主题统一

- **现状**：pi-web 是浅色主题（实测 body 背景 `rgb(255,255,255)`）；桌面壳自研 UI（设置/插件/模板/终端/托盘菜单）统一深色 `#1e1e2e`。
- pi-web 无独立主题系统（源码检索：命中项均为 Next.js 框架代码；设置页无主题切换实现）。
- **结论**：**不强行统一**。壳层强改 pi-web 样式（preload 注入 CSS）风险高（按钮/输入框等组件配色是浅色系，强行深色会破坏对比度）；pi-web 主题跟随上游。壳内已统一深色，作为品牌一致性基线。

### 1.2 CLI 命令能力

- **现状**：pi-web 输入框输入 `/` **无补全 UI**（实测）；但 pi 后端 prompt 通道**支持命令展开**（rpc.md 明确：扩展命令立即执行、`/skill:` 与模板命令展开）。
- 桌面壳已覆盖大部分命令的替代入口：`/tree`→侧边栏会话树、`/export`→导出 PDF、`/compact`→Compact 按钮、`/name`→自动命名。
